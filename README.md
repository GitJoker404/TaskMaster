# TaskMaster

TaskMaster - это программа для создания и отслеживания задач (например, "Купить молоко" или "Сделать домашку"). Она работает на компьютере через команды или в браузере!

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)

## Как установить
---
1. Скачайте проект с GitHub:
   ```bash
   git clone https://github.com/your-username/taskmaster.git
2. Установите нужные библиотеки:
   ```bash
   npm install

### Как использовать
---
Запустите программу:
```node index.j```
